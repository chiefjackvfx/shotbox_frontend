# ShotBox 3DE Import for Houdini

For Houdini 21/22 on Linux and Windows. Imports the Python files generated by
3DE's Houdini exporter, including ShotBox `*_hou.py` publishes. Imports add nodes;
they do not replace earlier imports or change the timeline/FPS. The exported
script determines transforms, scale, camera parameters, and animation timing.

## Install through ShotBox

In Settings → Plugins, select your Houdini **user preferences** folder (for
example `~/houdini22.0`, or your Windows Documents `houdini22.0` folder).
Click **Install / Update Houdini Plugin**, restart Houdini, then use the shelf
menu to enable **ShotBox**. Click **3DE Import**.

## Manual installation

1. Create `shotbox_3de_import` inside `$HOUDINI_USER_PREF_DIR`.
2. Copy this directory's `python` and `toolbar` folders into it.
3. Copy `shotbox_3de_import.json` into `$HOUDINI_USER_PREF_DIR/packages`.
4. Restart Houdini and enable the ShotBox shelf.

Do not edit `houdini.env` or your default shelf. The package points to the copied
files, so the ShotBox repository can be moved after installation.

## Import an export

Click **3DE Import** on the ShotBox shelf to open the file browser directly.
Select a 3DE Houdini `.py` export to import it, or cancel to leave the scene alone.
There is no action menu or history selection, and no publish-history file is required.
Paths must be accessible to Houdini; this tool does not translate Windows drives
or Linux mounts.

Imports execute the chosen Python export once, in one Undo group. Syntax errors
are caught before execution. For execution errors, inspect the console traceback;
if nodes were created, Undo removes that import. Use scripts you intend to run in
Houdini. No extra confirmation is added for each import.

Windows paths have automated coverage; actual Windows GUI validation requires a
Windows Houdini session.
